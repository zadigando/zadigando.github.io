Weloo

Athleisure · Drop Launch · weloo.com.br ↗

Visão Geral

A Weloo é uma marca brasileira de athleisure — estética entre moda e esporte. O Drop 01, coleção Flow, foi lançado com uma landing page dedicada focada em criar urgência e converter visitas em pedidos diretos.

Construída com React 18, TypeScript e Vite, a página conta com carrossel de produtos, countdown de lançamento e um carrinho completo com checkout via WhatsApp — sem necessidade de plataforma de e-commerce.

Animações fluidas com Framer Motion, validação de formulários com Zod, gerenciamento de estado assíncrono com React Query e estilo com Tailwind CSS + shadcn/ui.
