# zadigando.github.io

Personal portfolio website for Zadig de Bem — Full Stack Developer.

**Live:** [zadigando.github.io](https://zadigando.github.io)

---

## Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (custom, no framework) |
| Scripting | Vanilla JavaScript + jQuery |
| Icons | Font Awesome 6 |
| Fonts | Google Fonts (Source Sans Pro) |
| Email | EmailJS |
| Hosting | GitHub Pages |

---

## Projects showcased

- **CarbonoZero** — Carbon emissions monitoring platform built with Angular + C#
- **GZ Artigos Esportivos** — E-commerce built with Django
- More on [github.com/zadigando](https://github.com/zadigando)

---

## Structure

```
.
├── index.html            # Single-page portfolio
├── css/styles.css        # All styles
├── js/script.js          # Interactions & animations
├── assets/images/        # Local images
└── projects/             # Individual project detail pages
    └── carbonozero.html
```

---

## Running locally

```bash
git clone https://github.com/zadigando/zadigando.github.io.git
cd zadigando.github.io
# open index.html in your browser, or use a local server:
npx serve .
```
