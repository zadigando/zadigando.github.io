MCCI Prime Gifts

Brindes Corporativos · mcciprimegifts.com ↗

Visão Geral

A MCCI Prime Gifts é um estúdio de brindes corporativos premium com showroom físico em Ribeirão Preto/SP. O site institucional apresenta o catálogo, os diferenciais e facilita o contato com clientes corporativos.

Desenvolvido com React 19 e TanStack Start (SSR), com roteamento via TanStack Router, o site entrega tempo de carregamento mínimo com renderização no servidor e navegação instantânea no cliente.

Hospedado na Hostinger, com build via Vite 7, usando Tailwind CSS v4 e shadcn/ui para uma interface moderna e de alta performance.
