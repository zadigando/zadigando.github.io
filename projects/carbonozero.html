CarbonoZero

Sustentabilidade

Visão Geral

O CarbonoZero é uma plataforma desenvolvida para ajudar empresas a monitorar e reduzir suas emissões de carbono, incentivando práticas ecológicas através de um sistema de créditos.

A aplicação foi construída com Angular no frontend e C# / .NET no backend, com uma API REST robusta para comunicação entre as camadas e banco de dados SQL.

O sistema acompanha as iniciativas sustentáveis das empresas e as recompensa com créditos de carbono, criando um incentivo econômico para a responsabilidade ambiental.
