GZ Artigos Esportivos

E-commerce

Visão Geral

O GZ Artigos Esportivos é uma plataforma completa de e-commerce para produtos esportivos, desenvolvida com Django e uma arquitetura orientada a microsserviços.

O sistema inclui cadastro de usuários, carrinho de compras, processamento de pagamentos e gerenciamento de estoque. O backend usa Django para a loja principal e Flask para serviços auxiliares, com comunicação via RabbitMQ.

Toda a infraestrutura é containerizada com Docker, facilitando o deploy e garantindo consistência entre ambientes de desenvolvimento e produção.
